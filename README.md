# 🛍 ShopProject1

ShopProject1 — учебный Python-проект магазина, демонстрирующий работу с объектной моделью товаров, наследование классов, перегрузку операторов, итерацию по товарам категории, загрузку данных из JSON и тестирование с помощью pytest.

## 💡 Обзор

Проект реализует:

- базовый класс Product для всех товаров;

- категории товаров (Category) с защитой от добавления некорректных объектов;

- наследников товаров:

    - Smartphone — смартфоны;

    - LawnGrass — газонная трава;

- перегрузку операторов (__add__) для подсчёта общей стоимости товаров;

- строковое представление (__str__) для товаров и категорий;

- итерацию по товарам категории через отдельный итератор;

- загрузку данных из JSON;

- автоматические тесты на pytest.

## 🧠 Использование

Запуск демонстрационного примера:
~~~
python main.py
~~~

Пример загрузки данных из JSON:
~~~
from src.utils import load_categories_from_json

categories = load_categories_from_json("data/products.json")

for category in categories:
    print(category)
~~~
## 📊 Формат JSON

Файл data/products.json должен иметь формат:
~~~
[
  {
    "name": "Смартфоны",
    "description": "Описание категории",
    "products": [
      {
        "name": "Название товара",
        "description": "Описание товара",
        "price": 123.45,
        "quantity": 10
      }
    ]
  }
]
~~~
## 🧪 Тестирование

Проект покрыт тестами с использованием pytest.

Запуск тестов:
~~~
pytest
~~~

Тесты проверяют:

- корректность инициализации всех классов;

- работу счётчиков категорий и товаров;

- корректную работу __add__;

- запрет сложения товаров разных типов;

- защиту метода add_product() от некорректных объектов;

- итерацию по товарам категории;

- загрузку данных из JSON.

## 📋 Классы
### 📦 Product

Базовый класс для всех товаров.

### Атрибуты:

- name: str — название

- description: str — описание

- price: float — цена

- quantity: int — количество

### Возможности:

- строковое представление:
~~~
Название продукта, 80 руб. Остаток: 15 шт.
~~~

поддержка сложения товаров одного типа (__add__).

## 📱 Smartphone (наследник Product)

Дополнительные атрибуты:

- efficiency: float — производительность

- model: str — модель

- memory: int — объём памяти

- color: str — цвет

## 🌱 LawnGrass (наследник Product)

Дополнительные атрибуты:

- country: str — страна-производитель

- germination_period: int — срок прорастания (в днях)

- color: str — цвет

## 🗂 Category

Представляет категорию товаров.

### Атрибуты:

- name: str — название

- description: str — описание

- _products: List[Product] — список товаров (приватный)

### Свойства и методы:

- products — геттер для вывода товаров в строковом виде;

- add_product(product) — добавление товара (только Product и наследники);

- __str__ — строковое представление:
~~~
Название категории, количество продуктов: 200 шт.
~~~

### Счётчики класса:

- Category.category_count — количество категорий

- Category.product_count — общее количество товаров

## ➕ Операции с товарами

Товары одного типа можно складывать:
~~~
result = smartphone1 + smartphone2
~~~

Результат — общая стоимость всех товаров на складе:
~~~
price * quantity + price * quantity
~~~

❌ Сложение товаров разных классов запрещено:
~~~
smartphone1 + grass1  # TypeError
~~~
## 🔁 Итерация по товарам

Реализован вспомогательный класс-итератор для категории:
~~~
for product in category:
    print(product)
~~~

Методы:

- `__iter__`

- `__next__`

Позволяют последовательно перебирать товары категории.
